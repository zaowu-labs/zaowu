## Findings and repairs

| Priority | Finding                                                                                                                                                                                                                         | Repair and evidence                                                                                                                                                                                                                                       |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| P1       | Sync inferred discarded commits from the configured upstream, although it resets to origin. Missing/different upstreams and remote history rewrites could lose commits without `--discard-local`.                               | Compare commits against the actual origin branch and check again after fetch. Real Git fixtures cover missing/different upstreams and unrelated remote history.                                                                                           |
| P1       | Hard reset can delete obstructing untracked or ignored paths; the previous preview promised to preserve all untracked files.                                                                                                    | Detect collisions across the entire repository, including when invoked from a subdirectory. Require discard acknowledgement. Preserve unrelated files. Update the experience spec and user documentation.                                                 |
| P1       | Sync fingerprints included file names but did not bind staged or working-copy contents. Local edits during fetch were not rechecked.                                                                                            | Hash both tracked diffs, bind the cached remote target, and recheck branch, HEAD, content, and status after fetch. Fully qualify the remote ref so a tag cannot shadow it; reject detached HEAD before fetching.                                          |
| P1       | HTTP provider requests could follow redirects beyond the previewed endpoint; timeout protection stopped at response headers.                                                                                                    | Reject redirects, bound both header and JSON body reads, abort failed requests, and test fetchers that ignore abort signals. Extract transport policy into `packages/ai/src/transport.ts` while preserving public exports.                                |
| P1       | The locked XML parser had ten published advisories, including eight high-severity advisories.                                                                                                                                   | Update the compatible transitive dependency `@xmldom/xmldom` from `0.8.13` to `0.8.15`. Production audit changes from 8 high / 3 moderate to 0 high / 1 moderate. See the [upstream parsing advisory](https://github.com/advisories/GHSA-93r5-fhx6-vmg9). |
| P2       | Line-based YAML editing could replace nested keys, corrupt block scalars, or fail on flow mappings. Rewrites could silently drop keys inherited from Object.prototype.                                                          | Edit the parsed scalar source range, preserving surrounding content and comments. Use own-property checks for unknown keys. Reject non-object JSON roots and safely traverse recursive YAML aliases.                                                      |
| P2       | Normalized JSON column names were used to look up original object fields, losing values after trimming or deduplication. Prototype-named missing fields could produce inherited values or disappear from missing-value reports. | Separate original keys from display headers, use own-property lookups, and construct result records with `Object.fromEntries`.                                                                                                                            |
| P2       | Malformed provider content arrays could throw raw TypeErrors; Ollama accepted whitespace-only output despite the documented validation contract.                                                                                | Validate array shapes and null items before extracting text, and reject empty Ollama output with stable provider errors.                                                                                                                                  |

## Remaining risks and follow-up

- [GHSA-hp3w-g68c-fv3c](https://github.com/advisories/GHSA-hp3w-g68c-fv3c):
  `mammoth -> argparse -> sprintf-js` remains flagged as moderate, with no
  published patched version in the advisory. The checked Mammoth source imports
  argparse from its standalone `bin/mammoth`; ZaoWu uses the library entry point.
  This reduces the apparent reachability in ZaoWu but is not proof of universal
  non-exploitability. Keep the advisory visible and follow an upstream fix.
- Because CI runs unrestricted `pnpm audit --prod`, this moderate advisory can
  still fail that CI step. The successful local `verify` gate does not include
  the network audit and must not be interpreted as a clean production audit.
- If the project later makes the Git synchronization adversary-resistant,
  filesystem/ref changes in the final check-to-reset window and submodule
  behavior need a stronger execution model. The added checks protect ordinary
  preview/fetch/confirm flows; they do not make multiple Git commands atomic.
