## Reproduced failures and regression coverage

- Local HTTP servers exercise all three streaming protocols, split UTF-8 bytes,
  completion/usage, metadata, malformed events, truncated/empty answers, stalled
  bodies, cancellation before headers/during output/during Retry-After, and retries
  only before output. JSON bodies are bounded and remain one envelope.
- Real DOCX ZIP/XML fixtures cover inherited/strict headings, tables, lists, links,
  literal Markdown, corrupt/DTD XML, excessive nesting, and compressed oversized
  parts. PDF cases cover actual text, absent text/OCR, and concurrent shim cleanup.
  Long malformed HTML/Markdown delimiters complete without repeated rescanning.
- Actual multi-sheet XLSX fixtures cover missing/mixed cells and oversized sparse
  ranges. A highly compressed ZIP proves the actual inflation limit. CSV/JSON
  fixtures cover extra columns, nested records, invalid shapes, broken quotes,
  finite extreme averages, and size limits.
- Temporary Git repositories exercise Unicode/space/newline paths, rename stats,
  diff-like added content, and configured external diff/textconv traps. Index
  bytes, HEAD, status, and working files stay unchanged after preview/review.
- Three deterministic input-race tests failed before the final guards: replacing
  a document, table, or AI input between verification and execution could produce
  a different write/request. All now fail with OPERATION_PLAN_MISMATCH before any
  write/network call. Earlier inter-command file edits remain rejected too.
- Malformed model commit titles/findings fail visibly; unverified model locations
  lose their precise location and disclose the failed verification. Echo retains
  useful local results instead of masquerading as model review/commit text.

## Delivery and remaining limits

Merge only after all six supported CI jobs pass; release only from green main.
Post-publication acceptance verifies all eleven registry versions/latest tags,
archive integrity, signatures, source/workflow provenance, fresh installation,
and the published CLI's rich-input/streaming/JSON/cancellation behavior.

OCR, visual layout fidelity, formula evaluation, semantic review guarantees, and
structured multi-domain execution remain outside the documented foundation.
Model access is account-specific; API calls still require explicit selection and
confirmation. See MAINTENANCE for the next evidence-driven improvements.
